## 7. Handy facts for any content session

- A lesson id is `<track>/<NN-slug>` and is stored in the DB. Never rename a lesson folder.
- Per lesson: `lesson.md` (front matter `title`, `summary`, `plan_ids`), `quiz.yaml` (5 to 8 questions), 2 to 4 exercises (GenAI and agentic allow 4), each exercise with `prompt.md` (signature, rules, 2 examples, "Think first", "Hint"), `starter.py` (must FAIL the tests), `solution.py` (must PASS), `test_solution.py`.
- Chained exercises: a later `starter.py` holds earlier solutions as given code (header `# Given from earlier exercises. Do not change these.`, then `# Your task:`). No lambda, closures or classes in lesson or solution code (tests may use anything). Use `def`, not lambda, for key functions.
- Exercises that call a model use a fake client (`types.SimpleNamespace`), scripted replies with the call order stated in `prompt.md`, no network, no sleeping. Tool-call helper: `NS(id=..., function=NS(name=..., arguments=...))`. Default model string in solutions: `"qwen/qwen3.8-27b"`.
- Lesson style: simple English, plain meaning first, small runnable example with `# ->` output, one "Step by step" worked example per exercise pattern in a DIFFERENT domain than the exercise, "Try it live", "A little deeper", "Common mistakes", "Interview corner", "Summary" with a `Reference:` line. Run every code example before pasting its output (several `# ->` outputs were wrong the first time).
- Sequence rule: a lesson may only use concepts from earlier lessons of the same track and its prerequisites.
- YAML gotcha in `quiz.yaml`: `explain` or options with braces, colons or a leading quote need single quotes (or a block scalar).
- Helper scripts used to generate exercises lived in the old session scratchpad (`agw.py` with `mk(ex, given, task, stub, prompt, test, imports="")`, plus `a01.py` to `a05.py`). They may be gone. `mk` writes `starter.py` (given code plus stub), `solution.py` (given code plus solution), `prompt.md`, `test_solution.py`. Recreate it if needed; the finished exercise folders are the source of truth.
- After writing content, always run `uv run python scripts/validate_content.py`, then `uv run pytest`.
- Update `CLAUDE.md` (a dated entry in "GenAI + Agentic 9-week plan") and `reference/` (new methods) after each batch.
