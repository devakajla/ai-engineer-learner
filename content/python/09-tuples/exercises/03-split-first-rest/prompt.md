# Split first and rest

Write `split_first(items)` that returns a tuple `(first, rest)`, where `first` is the first item and `rest` is a **list** of all the other items. For an empty list return `(None, [])`.

```python
split_first([1, 2, 3])   # -> (1, [2, 3])
split_first(["x"])       # -> ("x", [])
split_first([])          # -> (None, [])
```
