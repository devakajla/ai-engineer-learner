# Group words by length

Write `group_by_length(words)` that returns a dict where each key is a word length and the value is the list of words with that length, in the original order.

```python
group_by_length(["hi", "yo", "hello", "hey"])
# -> {2: ["hi", "yo"], 5: ["hello"], 3: ["hey"]}
group_by_length([])   # -> {}
```
