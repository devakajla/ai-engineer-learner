# Rotate a list

Write `rotate(items, k)` that returns a new list rotated to the **right** by `k` places. `k` can be bigger than the list length. An empty list stays empty.

```python
rotate([1, 2, 3, 4, 5], 2)   # -> [4, 5, 1, 2, 3]
rotate([1, 2, 3], 3)         # -> [1, 2, 3]
```

Hint: slicing and `%` make this short.
