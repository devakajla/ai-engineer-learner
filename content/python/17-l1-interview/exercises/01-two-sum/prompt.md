# Two sum

Write `two_sum(nums, target)` that returns the **indexes** `(i, j)` with `i < j` of two numbers in `nums` that add up to `target`. Return `None` if no pair exists. Exactly one valid pair is guaranteed when one exists. It should be fast for big lists (one pass, use a dict).

```python
two_sum([2, 7, 11, 15], 9)    # -> (0, 1)
two_sum([3, 2, 4], 6)         # -> (1, 2)
two_sum([1, 2], 10)           # -> None
```
