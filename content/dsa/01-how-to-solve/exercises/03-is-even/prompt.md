# Is it even?

Write `is_even(n)` that returns `True` if `n` is even, else `False`. Zero and negative numbers count too.

```python
is_even(4)     # -> True
is_even(7)     # -> False
is_even(-2)    # -> True
```

**Think first:** what is the remainder when you divide an even number by 2?

**Hint:** the `%` operator.
