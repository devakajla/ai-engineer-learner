# Biggest of three

Write `biggest(a, b, c)` that returns the largest of three numbers. Do **not** use the built-in `max`; use `if`.

```python
biggest(1, 5, 3)     # -> 5
biggest(9, 2, 9)     # -> 9
```

**Think first:** keep a variable "best so far". Compare it with each number.

**Hint:** start with `best = a`.
