# FizzBuzz list

Write `fizzbuzz(n)` that returns a list for numbers 1 to `n`: `"FizzBuzz"` if divisible by 3 and 5, `"Fizz"` if by 3, `"Buzz"` if by 5, else the number itself.

```python
fizzbuzz(5)    # -> [1, 2, 'Fizz', 4, 'Buzz']
fizzbuzz(15)[-1]   # -> 'FizzBuzz'
```

**Think first:** in which order should you check the conditions?

**Hint:** check "both" first.
