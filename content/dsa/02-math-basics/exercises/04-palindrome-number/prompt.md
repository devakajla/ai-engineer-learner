# Palindrome number

Write `is_palindrome_number(n)` that returns `True` if a non-negative integer reads the same forwards and backwards.

```python
is_palindrome_number(121)    # -> True
is_palindrome_number(123)    # -> False
is_palindrome_number(10)     # -> False
```

**Think first:** you just wrote a function that reverses a number. Compare.

**Hint:** reverse it inside this function (peel digits), then compare with the original.
